# Code of conduct

This project exists to help people treat each other fairly at work. We ask the same of everyone who takes part here.

- Be kind, patient and respectful, especially with newcomers and people writing in their second language.
- Assume good intent; disagree about ideas, not people.
- Never post anyone's real personal data, ratings or comments: use the made-up example team.
- No harassment, discrimination or personal attacks, in any language.

Maintainers may edit or remove contributions that break these rules, and may block repeat offenders.
To report a problem privately, use GitHub's private reporting on this repository (Security → Report a vulnerability) and
say it is about conduct; the maintainers will reply within 7 days.
