# Fix a problem with the 360 evaluation

Follow `CLAUDE.md`. Ask what they see (the exact message, or a screenshot), then match it below. Explain the cause in one
sentence and the fix in numbered clicks. Full list: `docs/en/troubleshooting.md` (Arabic: `docs/ar/troubleshooting.md`).

**The page and signing in**
- **"This page is for the team of … only"**
  - Cause: the person opened the link with a personal account, or they are not in the Team tab (or marked "no").
  - Fix: open the link in a browser where only the work account is signed in; check the Team tab.
- **"You need access" / "Sorry, unable to open the file"**
  - Cause: the page is not published for everyone in the organisation.
  - Fix: Deploy → Manage deployments → edit → Who has access: anyone in the organisation → New version → Deploy.
- **The page shows old wording after a change**
  - Cause: a new version was not published.
  - Fix: Deploy → Manage deployments → pencil → Version: **New version** → Deploy. Check the dialog shows a new version
    number; the dropdown can quietly stay on an old one.

**Setup and the sheet**
- **The menu does not appear:** reload the sheet; wait 10 seconds. Check the script was saved (Extensions → Apps Script).
- **Google says "This app isn't verified":** normal for a script the organisation owns. Advanced → Go to (project name) →
  Allow.
- **"Not allowed: only the evaluation admin can do this":** the person running the menu is not the Admin email in
  Settings. Sign in as the admin, or correct the Admin email row.
- **Check reports a missing manager:** the Manager cell must be an email or the exact name as written in the Team tab.

**Emails**
- **Emails did not arrive:**
  - Check Gmail «Sent» of the admin's account.
  - Google Workspace allows about 1,500 emails a day, and a new account far fewer.
  - Ask people to look in Spam and Promotions.

**Uploading with clasp**
- **"User has not enabled the Apps Script API":** open https://script.google.com/home/usersettings, switch it on, wait a
  minute, run again.
- **Login problems:** run `npx --yes @google/clasp@3.4.1 logout`, then `login` again with the work account.
- **Anything else:** fall back to copy and paste (`org/build/Code.gs` into Extensions → Apps Script).

**Numbers look wrong**
- Run menu «Update results» again.
- Check «Review decisions» for a keep or exclude that changes the picture, and the «Flags» tab for excluded ratings.
- Results for a person appear only with at least the minimum group size of raters. That is on purpose.

If it is a real bug in the tool:
1. Reproduce it with the made-up example (menu «Try it»).
2. Write a failing test in `test/`, fix it, and run `npm test`.
3. Suggest they report it on GitHub **without any real names or data**.
