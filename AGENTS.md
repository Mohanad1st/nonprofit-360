# Guidance for AI coding assistants

This project's full guidance for AI assistants is in [CLAUDE.md](CLAUDE.md): who the users are (usually non-technical
nonprofit staff), the safety rules (their data stays in the private `org/` folder, nothing is sent to staff without a
clear yes, results stay locked with the admin), how the project is built, and the step-by-step setup flow in
[.claude/commands/setup-360.md](.claude/commands/setup-360.md). Any assistant should follow the same rules.
